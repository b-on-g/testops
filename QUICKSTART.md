## 📦 Что реализовано

### Основные компоненты

✅ **Генератор тест-кейсов** (`/generator`)
- Форма ввода требований и параметров
- Выбор продукта, типа теста, приоритета
- Поддержка OpenAPI спецификаций для API тестов
- Генерация ручных тест-кейсов (Allure TestOps as Code)
- Генерация автоматизированных тестов (pytest)
- Вкладки для просмотра кода (ручной/автоматизированный)
- Сохранение в библиотеку

✅ **Библиотека тест-кейсов** (`/library`)
- Таблица всех тест-кейсов с пагинацией
- Поиск по названию, фиче, тегам
- Фильтры: тип теста, приоритет, статус, продукт
- Статистика (всего, ручных, автоматизированных, критичных)
- Просмотр и удаление тест-кейсов
- Информация о последнем обновлении

✅ **Оптимизатор** (`/optimizer`)
- Анализ покрытия (по типам, приоритетам, продуктам)
- Поиск дубликатов тест-кейсов
- Выявление пробелов в покрытии
- Рекомендации по улучшению
- Вкладки для разных типов отчетов

✅ **Валидатор стандартов** (`/validator`)
- Проверка структуры AAA (Arrange-Act-Assert)
- Валидация Allure декораторов
- Проверка обязательных меток (owner, feature, story, priority)
- Проверка аннотаций типов
- Валидация отдельного тест-кейса или всей библиотеки
- Подробный отчет с рекомендациями

✅ **Настройки** (`/settings`)
- Cloud.ru Evolution API (ключ, модель)
- GitLab интеграция (токен, URL, project ID)
- Allure настройки (владелец по умолчанию)

### Технические возможности

✅ **CRUS-DB модели данных**
- `$bog_testops_profile` - профиль пользователя
- `$bog_testops_testcase` - тест-кейс с полной метаинформацией
- `$bog_testops_testsuite` - тест-сьют
- `$bog_testops_settings` - настройки приложения

✅ **$mol фреймворк**
- Реактивная архитектура (@$mol_mem)
- Декларативный UI (view.tree)
- Типизированные стили (view.css.ts)
- Автоматическая синхронизация через CRUS

✅ **Offline-first**
- Работает без сервера
- Все данные хранятся локально
- Автоматическая синхронизация между пользователями

## 📝 Структура навигации

Приложение использует `$mol_book2_catalog` с вкладками:

1. **Generator** - Генератор тест-кейсов
2. **Library** - Библиотека тест-кейсов
3. **Optimizer** - Оптимизатор тестов
4. **Validator** - Валидатор стандартов
5. **Settings** - Настройки

## 🎯 Примеры использования

### Создание UI тест-кейса

1. Откройте вкладку "Generator"
2. Выберите:
   - Продукт: `calculator`
   - Тип теста: `ui`
   - Приоритет: `CRITICAL`
3. Введите требования: "Проверка добавления сервиса Compute в конфигурацию калькулятора"
4. Нажмите "Генерировать"
5. Просмотрите сгенерированный код на вкладках
6. Нажмите "Сохранить в библиотеку"

### Создание API тест-кейса

1. Откройте вкладку "Generator"
2. Выберите:
   - Продукт: `compute`
   - Тип теста: `api`
   - Приоритет: `CRITICAL`
3. Введите требования: "Тестирование CRUD операций с виртуальными машинами"
4. Вставьте OpenAPI спецификацию в соответствующее поле
5. Нажмите "Генерировать"
6. Сохраните в библиотеку

### Анализ покрытия

1. Создайте несколько тест-кейсов через генератор
2. Откройте вкладку "Optimizer"
3. Нажмите "Анализировать"
4. Просмотрите результаты на вкладках:
   - Покрытие - статистика по типам и приоритетам
   - Дубликаты - повторяющиеся тест-кейсы
   - Пробелы - непокрытые сценарии
   - Рекомендации - советы по улучшению

### Валидация стандартов

1. Откройте вкладку "Validator"
2. Вставьте код тест-кейса в поле ввода
3. Нажмите "Проверить"
4. Получите детальный отчет о соответствии стандартам
5. Или нажмите "Проверить все" для анализа всей библиотеки

## 🔧 Технические детали

### Формат генерируемого кода

**Ручной тест-кейс (Allure TestOps as Code):**
```python
@allure.manual
@allure.label("owner", "qa-team")
@allure.feature("compute")
@allure.story("manual")
@allure.suite("manual")
@mark.manual
class TestCompute:
    @allure.title("Test scenario")
    @allure.link("JIRA-123", name="JIRA-123")
    @allure.tag("CRITICAL")
    @allure.label("priority", "CRITICAL")
    def test_manual_scenario(self) -> None:
        with allure_step("Step 1"):
            pass
```

**Автоматизированный тест (pytest):**
```python
import pytest
from playwright.sync_api import Page, expect
import allure

@allure.feature("compute")
@allure.story("UI")
class TestUICompute:
    @allure.title("Test scenario")
    def test_ui_scenario(self, page: Page):
        with allure.step("Navigate"):
            page.goto("https://example.com")
```

- Профиль пользователя
